# Eat Well

先解决用户眼前的饮食选择，再按需要计算。食物可获得、预算、口味和执行难度会影响方案，不只优化营养数字。

## 接待与检索

沿用 [接待与反馈](../references/intake-and-feedback.md) 中已知信息。完整饮食方案按需补充年龄段、目标、身高体重及近期趋势、活动量、常见三餐、过敏与饮食限制、预算、做饭或外食条件，以及相关疾病、用药和孕产状态。不知道体脂可留空；不为了回答“蛋白粉要不要买”要求完整档案。

从 [索引](../knowledge-base/topic-index.md) 默认选择 1–3 份主题：

- 一般营养与蛋白目标：[运动营养基础](../knowledge-base/Eat-Well/fundamentals/sports-nutrition-basics.md)。
- 减脂或特殊人群：[减脂与特殊人群食养](../knowledge-base/Eat-Well/weight-management/fat-loss-and-special-populations.md)。
- 补剂与日常活动：[营养补剂与日常活动](../knowledge-base/Eat-Well/supplements-and-activity/supplements-and-daily-activity.md)。
- BCAA/碳酸氢钠/甜菜根/瓜氨酸/HMB/电解质/铁 等第二梯队补剂：[补剂第二梯队与证据边界](../knowledge-base/Eat-Well/supplements-and-activity/second-tier-supplement-evidence.md)。

## 决策与计算

1. **先检查适用性**：儿童、孕哺期、肾病、糖尿病等不使用默认健康成人减脂或高蛋白模板。极端节食、暴食清除、明显能量不足或不明原因快速掉重时先转专业评估。
2. **确定能量起点**：优先用足够时间的体重与摄入记录估计维持水平；没有记录时，可用已说明名称与输入的通用估算公式，但要标为估算并解释活动系数误差。缺少公式所需数据时给份量法或补问，不能编造基础代谢和消耗。运动手表热量不全额直接“吃回”。
3. **定蛋白**：健康抗阻训练成人按主题规则选择体重口径；新手可从约 1.6 g/kg/天起。减脂期瘦体重口径与体重口径必须区分，不能把 2.3–3.1 g/kg 瘦体重写成同等体重剂量。未知瘦体重时不用体脂秤数字假装精确。
4. **安排脂肪与碳水**：在总能量和蛋白目标内，结合训练需求、口味和饱腹感分配；耐力运动员剂量不直接套普通力量训练者。宏量供能按蛋白与碳水约 4 kcal/g、脂肪约 9 kcal/g 核算，目标范围不能互相矛盾。
5. **落到食物**：按三餐或用户已有节奏分配蛋白、主食、蔬果和脂肪；给便利店、外卖或素食替代。注明生重、熟重、可食部和品牌差异，估算用范围，不把“100 g 食物”当“100 g 蛋白”。
6. **补剂按缺口评估**：先判断食物是否能满足。说明用途、适用人群、证据、已知风险和交互；已有用药、疾病或治疗性剂量时建议医生/药师核对。不处方、不调整药物，不承诺补剂带来固定效果。

选择证据范围与实践起点时明确区分；遇到知识文件中的过强结论或数字冲突，保留不确定性，不把群体阈值当个体硬性底线。

## 交付与复盘

完整方案覆盖：目标与适用条件、能量估算依据或份量法、每日蛋白及计量口径、三餐安排与替代、训练前后必要调整、记录方式、复查时间和风险边界。用户只问一顿怎么吃时先给那顿成品。

| 反馈 | 调整 |
| --- | --- |
| 趋势符合目标、饥饿可管理、训练表现稳定 | 维持，避免因单次体重波动改热量 |
| 足够时间的同条件趋势偏离目标 | 先核对完成率、份量、周期与水分因素，再小幅改能量或日常活动中的一个变量，说明复查条件 |
| 下降过快、疲劳或训练表现下降 | 缩小缺口，检查恢复与能量不足；持续症状转介 |
| 外食多或难坚持 | 简化为可执行的份量与固定选择，不一味收紧数字 |
| 一次吃多 | 恢复正常餐次，不补偿性禁食或加练 |

体重目标一般用数周趋势判断；没有足够数据不声称平台期。用 [领域案例与场景检查](../references/domain-worked-examples.md) 对照计算和交付。需要跨对话档案时按 [长期档案](../references/long-term-memory.md)，未启用不声称已保存。
