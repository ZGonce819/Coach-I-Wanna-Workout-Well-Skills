# 关键处方原文核验

核验日期：2026-10-04。文献编号以[导读](topic-index.md)为准，与根目录 REFERENCES 的条目序号不同。

本轮检查 15 份本地来源文件中的核心训练、蛋白、体重管理、拉伸与疼痛处方，并将修正写回对应主题。**这是第一轮关键处方核验，不代表全部 18 个主题或 111 个引用已逐条核实。**

本轮使用本地来源正文及部分英文摘要核对结论。引用统一标注文献编号与名称，通过题名、作者／机构、年份、DOI 或公开链接进行网络检索，不要求具体页码。“原文核对”指直接核对指南／综述／meta 本身，不表示已重读其中引用的每项原始试验。

## 核验结果与修正

| 处方或关键判断 | 来源文献 | 结果及处理 |
|---|---|--- |
| 超出目标次数后加重 2%–10% | [1] ACSM 抗阻训练立场声明（2009） | 英文摘要支持超出目标 1–2 次后加重；连续两次条件在译本中可见。删除按固定周数自动加重的口径；英文全文仍待核对 |
| 最大力量重负荷组间休息 | [1] ACSM 抗阻训练立场声明（2009） | 3–5 分钟；与 [3] 增肌多关节至少 2 分钟区分，不能合并为统一 2–3 分钟 |
| 力竭与非力竭 | [2] Grgic 等力竭训练 meta 分析（2022） | 总体力量 ES=−0.09，增肌 0.22，均不显著；配平力量 ES=0.01（95%CI −0.12–0.15）；未配平力量 −0.32，有利非力竭。纠正总体／亚组混用与符号 |
| 有经验者必须 RIR 0–1 | [2] Grgic 等力竭训练 meta 分析（2022）；[3] IUSCA 增肌训练立场声明（2021） | 不成立；有经验者更接近力竭可能重要，但不支持统一 RIR 门槛。新手也非必须接近力竭 |
| 每周每肌群 10 组、20 组上限 | [3] IUSCA 增肌训练立场声明（2021） | 约 10 组为一般优化参考，低容量也可有效；上限未定，超过 20 组的研究仍可能获益。5.4%／6.6%／9.8% 是研究组均值 |
| 每四周必须加 20% | [3] IUSCA 增肌训练立场声明（2021） | 原文为需要加量时，增幅宜限制在此前容量约 20%／约四周；非必须执行的加量任务 |
| 单次 10 组硬上限 | [3] IUSCA 增肌训练立场声明（2021） | 审慎参考，非已确定硬上限 |
| 增肌组间休息 | [3] IUSCA 增肌训练立场声明（2021） | 多关节至少 2 分钟，单关节／部分器械 60–90 秒；力竭可能需更久，没有统一超过 3 分钟规定 |
| 力量与有氧完全没有干扰 | [3] IUSCA 增肌训练立场声明（2021） | 适中训练量下肌肥大未见明确干扰，研究有限；不可泛化为所有训练量、最大力量和爆发力 |
| 每 6–8 周减量一周至 50%–60% | [3] IUSCA 增肌训练立场声明（2021） | 未核实此固定处方；改为依据疲劳与表现决定的应用策略，同步修正睡眠主题的交叉引用 |
| 拉伸 15–30 秒 ×2–4、每周至少 2–3 天 | [7] Page 拉伸综述（2012） | 一般健身参考可保留；60 秒来自特定老年研究，不外推所有挛缩患者；PNF 不默认最高收缩强度 |
| 静态拉伸 60 秒阈值 | [8] Behm 等急性拉伸系统综述（2016） | 是每肌群累计时长。≥60 秒平均 −4.6%、<60 秒 −1.1%；删除“单次 ≥60 秒且 ≥6 次”的规则。不能预测个人必然下降 |
| 腰痛运动／手法等级 | [9] George 等腰痛临床实践指南（2021） | 慢性运动 A、急性一般运动 C；急慢性推／非推松动 A、按摩 B、慢性辅助干针 C；机械牵引 D 针对慢性伴腿痛。纠正统写为 C 或无范围限制 |
| 跟腱机械负荷与频率等级 | [10] Martin 等跟腱中段病指南（2018） | 机械负荷 A，需无推定结构脆弱；每周至少两次且耐受内 F，不能全写为 A |
| 跟腱辅助方法 | [10] Martin 等跟腱中段病指南（2018） | 夜用夹板反对 C、弹性贴扎反对 F、硬性贴扎可考虑 F；跟垫／矫形器／低强度激光 D 为证据矛盾 |
| Alfredson 与 80% 恢复 | [10] Martin 等跟腱中段病指南（2018） | 80% 是指南引述病例系列 5 年 27/34 的转归，渐进负荷为 12 周至 6 个月；非固定 12 周治愈保证。历史离心方案原始试验待直接核对 |
| 髌股痛运动与辅助治疗 | [11] Willy 等髌股痛指南（2019） | 髋+膝运动 A；髋可早期偏重而非必须先练。足矫形器最长约 6 周并结合运动 A、个体贴扎最长约 4 周 B；干针反对 A、单独手法反对 A、生物物理因子反对 B、支具反对 B |
| WHO 腰痛结构化运动 | [12] WHO 慢性原发性腰痛指南（2023） | 有条件推荐使用、低确定性；纠正“强推荐”。整体方案个体化，不规定每周 3–5 次、30–45 分钟或核心 RIR 1–2 |
| WHO TENS／牵引 | [12] WHO 慢性原发性腰痛指南（2023） | 均不应作为慢性原发性腰痛的常规照护，有条件反对、极低确定性；纠正将 TENS 列为推荐辅助 |
| 蛋白每日与单次 | [13] ISSN 蛋白与运动立场声明（2017） | 每日 1.4–2.0 g/kg 体重；一般单次 0.25 g/kg 或 20–40 g，约每 3–4 小时分配。纠正将 0.4 g/kg 写为所有人的统一推荐 |
| 减脂蛋白 2.3–3.1 g/kg | [14] ISSN 膳食与体成分立场声明（2017） | 使用 FFM，针对较瘦、有抗阻训练经验、热量赤字的运动者；不泛化至所有减脂会员 |
| 每周减重 0.5%–1.0% | [14] ISSN 膳食与体成分立场声明（2017） | 来自健美备赛建议，不是所有成人按体脂分类的统一处方；较瘦者宜更慢 |
| 蛋白 1.62 g/kg 断点 | [15] Morton 等蛋白补充 meta 分析（2018） | 95%CI 1.03–2.20；分段与线性模型比较 p=0.079，未显著。保留实践参考，删除硬性平台解释 |
| 碳水、脂肪、补液 | [16] ACSM/ADA/DC 运动营养立场（2009）中文译本与英文摘要 | 译本支持碳水 6–10 g/kg（按训练等条件调整）、脂肪 20%–35%、失重 0.5 kg 补液 450–675 mL。英文摘要确认总体原则，但这些剂量仍属译本核对，英文全文待核对 |
| 肥胖减重目标与能量缺口 | [17] 《体重管理指导原则（2024年版）》 | 原文初始 0.5–1 kg／周、6 个月 5%–15%；减能量 500–1000 kcal 或 30% 有出处，但须结合风险和营养，不是所有健康减脂者自动起点。5%–10% 示例标为应用模板 |
| 肥胖运动剂量 | [17] 《体重管理指导原则（2024年版）》 | 有氧逐步增加，参考 ≥250 分钟／周；抗阻表列 65%–85%1RM、6–12 次、3–5 组、休息 2 分钟。表格人群／运动风险条件不能省略 |
| CKD 蛋白与水 | [24] 《成人慢性肾脏病食养指南（2024年版）》 | 区分 1–2 期约 0.8、3–5 期非透析约 0.6、透析 1.0–1.2 g/kg 理想体重；糖尿病和腹膜透析等有调整。正常尿量无水肿的水量不可套至透析／少尿患者，全部由专科决定 |
