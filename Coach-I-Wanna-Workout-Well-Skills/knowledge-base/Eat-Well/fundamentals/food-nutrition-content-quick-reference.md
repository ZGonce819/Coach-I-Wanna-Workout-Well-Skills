# 食物营养含量速查（常见食物）（主题指南）
> [返回导读与主题索引](../../topic-index.md)
> 本文件为本主题的主要归属入口；交叉领域请按导读索引读取关联文件。

> 本文件供 AI 教练在**配餐估算**时使用：某食物每 100g 约含多少热量/蛋白/碳水/脂肪、常见份量怎么换算、外食怎么估、营养标签怎么看。**本文件先明确立场：食物营养数值是"参考近似值"——同一食材因品种、部位、烹饪方式差异可达 ±20–30%，估算以"大致量级 + 一致性"为目标，不追求逐克精确；包装食品以营养成分表为准，散装食材以权威数据库（中国食物成分表 [206] / USDA FoodData Central [207]）为准。** 依据：中国食物成分表（标准版第 6 版）[206]、USDA FoodData Central [207]、中国居民膳食指南（2022）[26]。
>
> **适用边界：肾病/糖尿病等需要精确管理营养素者、临床营养治疗 → 以营养师/医生处方为准，本表仅作通用参考，不替代个体化计算。**

## 一、本主题回答哪些问题
1. 鸡胸/鸡蛋/米饭/香蕉每 100g 多少热量和蛋白？
2. 想凑够每天蛋白目标，吃哪些食物最方便、怎么算？
3. 一掌心肉/一拳头饭/一把坚果 ≈ 多少克？
4. 外食/快餐怎么估热量？
5. 增肌和减脂时怎么用这个表配餐？
6. 营养成分表怎么看？每 100g 和每份有什么区别？
7. 同一食物不同做法（煎/炸/煮）差多少？

## 二、核心结论（先给判断）
- **蛋白优质来源（每 100g 可食部参考）**：鸡胸肉 ≈ 蛋白 23g / 脂肪 1.5g / 约 120 kcal；鸡蛋（全蛋）≈ 蛋白 13g / 脂肪 9g / 约 140 kcal（1 个约 50g，蛋白约 6–7g）；瘦牛肉 ≈ 蛋白 20–22g；猪里脊 ≈ 蛋白 20g；三文鱼 ≈ 蛋白 20g / 脂肪 13g（含 omega-3）；虾仁 ≈ 蛋白 18–20g / 脂肪 1g；北豆腐 ≈ 蛋白 12g；黄豆（干）≈ 蛋白 35g / 脂肪 16g [206]。
- **主食碳水（每 100g 熟重参考）**：米饭 ≈ 碳水 26g / 约 116 kcal；馒头 ≈ 碳水 47g / 约 220 kcal；面条（熟）≈ 碳水 25g / 约 110 kcal；红薯（熟）≈ 碳水 20–24g / 约 90–100 kcal；燕麦（干）≈ 碳水 60g / 蛋白 13g / 约 380 kcal [206][207]。
- **脂肪/坚果（密度最高）**：食用油 ≈ 900 kcal / 脂肪 100g；杏仁 ≈ 脂肪 50g / 蛋白 21g / 约 580 kcal；花生 ≈ 脂肪 49g / 蛋白 25g / 约 567 kcal；核桃 ≈ 脂肪 65g / 约 650 kcal。**坚果按"把"算（20–25g），不按"袋"算** [206]。
- **份量换算（手掌法，参考）**：1 掌心（不含手指）瘦肉 ≈ 80–100g；1 拳头熟米饭 ≈ 150–200g；1 拇指油脂 ≈ 10g；1 把坚果 ≈ 20–25g；1 个鸡蛋 ≈ 可食 50g；1 盒牛奶 250ml ≈ 蛋白 8g / 钙约 260mg [26]。
- **外食热量密度规律**：油炸 > 红烧 > 清蒸/白灼；糖饮料与奶茶是隐性碳水大户；同样食材"做法"比"食材本身"更能决定热量（见决策规则）[26][206]。
- **标签阅读**：中国预包装食品营养标签按**每 100g（或每 100ml）**标注能量与蛋白质/脂肪/碳水/钠，另附"每份"与 NRV%；看热量先看 100g 口径，再换算自己吃的份量 [26]。

## 四、决策规则（如果……则……）
### 配餐估算
- 如果会员问"我怎么吃够蛋白" → 给常见高蛋白食物表 + 份量换算；建议每餐 1 掌心蛋白源 + 按需补充 [206]。
- 如果会员想减脂 → 优先低能量密度选择（蒸/煮/烤、去皮禽肉、多蔬菜），用份量控制（一拳头主食/一掌心肉/一拇指油）[26]。
- 如果会员想增肌 → 在维持/盈余下均匀分配蛋白（每餐 20–40g），主食与油脂按目标热量补足 [15][206]。

### 外食
- 如果会员问"外食怎么点" → 优先清蒸/白灼/烤制，汤汁不拌饭，饮料换无糖；同店同菜先看可查营养信息（连锁店一般官网/小程序有）[26]。
- 如果会员吃快餐 → 用"每 100g 参考值 + 常见份量"估算（汉堡/薯条/炸鸡数值见第七节），不必精确到个位数 [206][207]。

### 标签
- 如果会员问"营养成分表怎么看" → 先看每 100g 口径的能量与三大营养素，再看 NRV% 判断高低（≥20% NRV 为高、≤5% 为低，用于钠/糖/脂肪判断）[26]。
- 如果标签按"每份"且份量很小 → 换算成自己实际吃的量，不被小份量误导 [26]。

## 五、误区澄清
- **误区："只有鸡胸肉才算蛋白"** → 蛋、奶、鱼、豆制品、瘦红肉都是优质蛋白来源，多样化更可持续 [206][26]。
- **误区："香蕉是高热量水果"** → 香蕉约 89–93 kcal/100g（碳水 22g），与多数水果相当；"高热量"印象来自大份量 [206][207]。
- **误区："坚果健康所以可以放开吃"** → 坚果约 550–650 kcal/100g，按"把"（20–25g）计，不是零食袋 [206]。
- **误区："蛋白粉是药/必须吃"** → 蛋白粉是蛋白补剂，非必需；优先食物来源（见 [补剂第二梯队](../../Eat-Well/supplements-and-activity/second-tier-supplement-evidence.md)）[206][15]。
- **误区："营养数字必须算到克"** → 食物成分有天然变异，估算到"量级+份量"即可，一致性比精确更重要 [206][207]。

## 六、证据限制与来源说明
- 全部数值为**常见品种/部位/做法的参考均值**（综合中国食物成分表第 6 版 [206] 与 USDA FoodData Central [207]），同一食物数据库间、品种间、烹饪方式间差异可达 ±20–30%。
