# 补剂第二梯队与证据边界（主题指南）
> [返回导读与主题索引](../../topic-index.md)
> 本文件为本主题的主要归属入口；交叉领域请按导读索引读取关联文件。

> 本文件供 AI 教练处理"核心补剂之外"的一类问题：会员问 **BCAA、碳酸氢钠、甜菜根汁/硝酸盐、瓜氨酸/精氨酸、HMB、运动饮料/电解质粉/盐片、铁剂** 要不要吃、吃多少、对谁有用。核心补剂（肌酸、β-丙氨酸、咖啡因、维生素D、omega-3）的剂量与证据见 [营养补剂与日常活动](../../Eat-Well/supplements-and-activity/supplements-and-daily-activity.md) [36]–[44]，蛋白补剂与基础补水见 [Eat Well](../../Eat-Well/fundamentals/sports-nutrition-basics.md) [13][16]，药物×补剂交互见 [药物补剂相互作用](../../Eat-Well/supplements-and-activity/drug-supplement-interactions.md) [84]–[89]，本文件不重复。**本文件先明确立场：第二梯队补剂的共同特点是"场景证据"——只在特定运动场景、特定人群中显示边际收益，多数对健康健身者的日常训练不是必需品；教练按场景给条件性建议，不把任何一项当作默认推荐。** 依据：ISSN 立场声明（碳酸氢钠、HMB）、系统综述与 meta（硝酸盐、瓜氨酸、HMB 老年、铁）、ACSM 运动补液立场。**本文件是教练决策参考，不是诊断或处方工具。**
>
> **适用边界：本文件面向"健康成人运动人群"。儿童青少年、孕期/哺乳期、慢病人群（肾病、心血管病、高血压限钠、出血性疾病、用药者）不适用默认剂量，分别转 [Eat Well](../../Eat-Well/weight-management/fat-loss-and-special-populations.md)（慢病食养）、[药物补剂相互作用](../../Eat-Well/supplements-and-activity/drug-supplement-interactions.md) 与 [Recover Well](../../Recover-Well/recovery-and-pain/recovery-and-pain-management.md)。铁剂与任何"处方级"补充必须由医生/营养师评估，教练不指导剂量。**

## 一、本主题回答哪些问题
1. 练后/训练中喝 BCAA 有必要吗？和乳清蛋白比哪个好？
2. 碳酸氢钠（小苏打）能提升高强度表现吗？怎么吃、有什么副作用？
3. 甜菜根汁/硝酸盐补剂对耐力有用吗？谁适合、提前多久喝？
4. 瓜氨酸/精氨酸（"泵感补剂"）能增肌吗？证据到什么程度？
5. HMB 是什么？年轻人吃了长肌肉吗？老年人有用吗？
6. 运动饮料/电解质粉/盐片什么时候才需要？普通健身房 1 小时力量训练要喝吗？
7. 女性耐力运动员/素食者要不要补铁？教练能直接推荐吗？
8. 这些补剂和核心补剂（肌酸/咖啡因/β-丙氨酸）怎么组合、谁更优先？

## 二、核心结论（先给判断）
- **BCAA：健康健身者常规不需要**。单独补充 BCAA 不能净增加肌肉蛋白合成——它只提供 9 种必需氨基酸中的 3 种，"触发信号"不等于"合成底物"，其余 EAA 不足时合成受限；相同亮氨酸量下不优于全蛋白/乳清 [151]。已规律摄入蛋白质的会员，BCAA 几乎无额外价值（共识，呼应 [13]）。
- **碳酸氢钠：高强度 1–10 分钟（或反复冲刺）场景有 2–3% 的小增益，是"比赛日工具"而非日常补剂**。ISSN 立场：0.2–0.5 g/kg 可改善肌耐力、格斗、高强度骑行/跑步/游泳/赛艇表现 [152]；主要代价是胃肠道不适（腹泻/腹胀），渐进剂量与胶囊剂型可减轻（应用建议）。
- **硝酸盐/甜菜根：对 ≥12 分钟耐力任务有小到中等增益，对 <12 分钟或无氧/冲刺场景证据弱**。meta（47 研究）显示时间至力竭改善最一致，计时赛约 1–3% [153]。典型用法：5–9 mmol 硝酸盐（约 500 mL 浓缩甜菜根汁），赛前 2–3 小时或连续 5–15 天。
- **瓜氨酸/精氨酸：对力量/功率是"小效应可选边际项"，对耐力无显著证据**。高强度力量与功率 meta 显示小增益（重复次数约 +6%、RPE 与酸痛降低）[154]；有氧/耐力方向的 meta 未达显著 [154]。剂量约瓜氨酸 6–8 g 练前 60–90 分钟；"泵感"不是增肌证据。
- **HMB：健康年轻成人 RET 期间不显著增加瘦体重/力量；老年与失用场景证据更强**。ISSN 立场：年轻受试者中 HMB 对 FFM/力量无显著增益（仅总体重小效应）[155]；>50 岁人群 meta（21 RCT，n=1935）显示 3 g/天、持续 >12 周可改善肌肉质量、力量与身体功能 [156]。
- **电解质/运动饮料：普通健身房 ≤1 小时的力量训练基本不需要；长时（>1 小时）、高温、大量出汗（>1.2 L/h）或"咸汗"者才考虑含钠饮品**。ACSM 立场：<1 小时温和环境运动白水足够；>1 小时或高温大量出汗时，含钠饮品（约 0.5–0.7 g/L 钠）有助于补水与体液平衡 [158]。电解质粉不是"练前必需"，更不是直接增能补剂。
- **铁：教练识别高危人群并提示筛查，绝不直接推荐剂量**。女性耐力运动员、素食者、经期量大人群缺铁常见；铁缺乏可降低耐力 3–4%，补足后改善可达 2–20% [157]。铁过量有害，补铁需医学评估（血清铁蛋白检测后由医生/营养师处方）。
- **优先级提醒：这些补剂的共同前提仍是"训练系统、蛋白与能量达标、睡眠足够"**（呼应 [13]）；第二梯队补剂的证据强度整体低于肌酸/咖啡因，先满足基础，再谈边际选项（共识，交叉 [36][37]）。

## 三、适用人群与条件
- **BCAA**：健康成人；对蛋白摄入已达标者无额外价值；唯一可能场景是"空腹/长时间训练中的主观疲劳"（证据中等、与食物蛋白重叠），不构成购买理由。
- **碳酸氢钠**：参与 1–10 分钟高强度或反复冲刺项目的**比赛/测试日**；训练日不作为常规。高血压、心衰、肾病限钠、胃病者转介医生；儿童青少年不自行使用（应用建议）。
- **硝酸盐/甜菜根**：≥12 分钟耐力项目（计时赛/长距离）的健康成人；血压偏低者注意（硝酸盐可轻度降压）；口腔卫生差或使用抗菌漱口水者反应可能减弱（机制提示，非硬证据）。
- **瓜氨酸/精氨酸**：追求高强度力量/功率训练边际增益的成人；有氧耐力方向无证据支持。低血压者注意扩张血管效应（应用建议）。
- **HMB**：老年（>50 岁）、长期卧床/减重期保护瘦体重、素食者等特定人群是主要证据场景；健康年轻健身者非必需 [155][156]。
- **电解质**：>1 小时连续运动、高温环境、出汗率 >1.2 L/h、出汗"咸"（衣服留盐渍）、超耐力（>4 h，需警惕低钠血症）人群 [158]。
- **铁**：女性耐力运动员、素食/纯素者、青少年女运动员、经期量大、反复抽血/献血者——高危人群**建议检测血清铁蛋白**，教练不直接开补铁处方 [157]。

## 四、决策规则（如果……则……）
### BCAA
- 如果会员问"练后要不要喝 BCAA" → 蛋白达标者不需要；练后 0.4 g/kg/餐的完整蛋白（食物或乳清）在增肌上等同或优于 BCAA（相同亮氨酸前提下）[151]。不宣称 BCAA 比蛋白粉更能增肌。
- 如果会员是"空腹晨练/长时间训练怕掉肌肉" → 不是掉肌肉危机；可在训练中/前后安排含完整蛋白的小餐，BCAA 不是必需品（机制与 [13] 一致）。
- 如果会员已经在吃 BCAA 且想停 → 停用无"戒断"；可平滑停用（应用建议）。

### 碳酸氢钠
- 如果会员参加 1–10 分钟高强度比赛或反复冲刺测试 → 可条件性介绍：0.2–0.5 g/kg 溶于水，赛前 60–120 分钟；建议先训练日试耐受，渐进剂量（如首日 0.1 g/kg 递增）或胶囊剂型减轻胃肠不适 [152]。
- 如果会员有高血压/心衰/肾病/限钠医嘱或胃病 → 转介医生，教练不指导剂量 [152]。
- 如果会员问"小苏打当日常补剂吃行不行" → 不行；高钠负荷对日常无增益且增加胃肠风险（应用建议）。

### 硝酸盐/甜菜根
- 如果会员练/赛 ≥12 分钟耐力（骑行计时赛、长跑、团队项目）→ 可条件性介绍：浓缩甜菜根汁约 5–9 mmol 硝酸盐，赛前 2–3 小时急性摄入，或连续 5–15 天慢性摄入 [153]。
- 如果会员是 <12 分钟或无氧/冲刺为主 → 证据弱，不推荐为表现必需品（诚实标注不确定）。
- 如果会员血压偏低或在服降压药 → 提示硝酸盐可轻度降压，转介医生评估（应用建议）。

### 瓜氨酸/精氨酸
- 如果会员问"泵感补剂能长肌肉吗" → 区分：瓜氨酸对高强度力量/功率有小而一致的增益（重复次数、RPE），但"泵感"本身不是增肌证据；增肌仍靠渐进负荷与蛋白 [154]。
- 如果会员追求耐力增益 → 明确：有氧/耐力方向 meta 无显著获益，不建议为此购买 [154]。

### HMB
- 如果会员是健康年轻健身者 → 不推荐为增肌必需品；RET 中无显著 FFM/力量增益 [155]。
- 如果会员 >50 岁、减重期、长期卧床后恢复、素食 → 可条件性介绍：HMB 3 g/天、与抗阻训练配合、持续 >12 周，对肌肉质量/力量/功能有证据支持 [156]；慢病与用药者先咨询医生。

### 电解质/运动饮料
- 如果会员在健身房做 ≤1 小时力量训练（常温环境）→ 白水足够；不需要电解质粉/运动饮料 [158]。
- 如果会员长时耐力/高温/大量出汗 → 含钠饮品（约 0.5–0.7 g/L 钠）比白水更利于补液；按渴感+体重变化补水，不建议固定"每小时强制喝多少"（[158]，呼应 [16]）。
- 如果会员问"电解质粉能不能当日常饮品" → 普通饮食+短时训练不需要；钠摄入超标人群（高血压）转介医生（应用建议）。
- 如果会员超耐力（>4 h）大量补水 → 提示低钠血症风险：补液需含钠，不单喝白水 [158]。

### 铁
- 如果会员是女性耐力运动员/素食/经期量大且疲劳、耐力下降 → 教练动作：提示"建议查血清铁蛋白"，说明铁缺乏可影响耐力（3–4% 降低，补足后改善 2–20%）[157]；不给出剂量、不推荐自购铁剂。
- 如果会员已由医生开铁剂 → 提示按医嘱服用、随诊复查；铁剂与咖啡/茶间隔（吸收干扰为一般临床常识，非本文件新证据）。
- 如果会员想自行补铁"预防" → 不推荐；铁过量（尤其非血红素铁）有氧化与蓄积风险，无缺乏证据时不预防性服用 [157]。

## 五、禁忌与转介
- **碳酸氢钠**：高血压、心衰、肾病、限钠饮食、胃溃疡/胃病、利尿剂使用者 → 医生评估 [152][89]。
- **硝酸盐/甜菜根**：低血压、服硝酸酯类/降压药 → 医生评估；孕哺期不自行使用（应用建议）。
- **瓜氨酸/精氨酸**：低血压、服降压药/硝酸酯 → 注意叠加降压（应用建议）；疱疹病史者精氨酸需谨慎（一般临床提示，标注为常识性注意）。
- **HMB**：肾功能异常、孕哺期、儿童 → 医生评估 [156]。
- **电解质**：心衰、肾病、高血压限钠 → 高钠补剂须医生指导 [158][89]。
- **铁**：铁剂过量有害；血色病/铁过载家族史、反复输血、肝病者禁用自补；儿童补铁必须医生处方 [157]。
- **通用红线**：会员在服处方药并想用任何新补剂 → 按 [药物补剂相互作用](../../Eat-Well/supplements-and-activity/drug-supplement-interactions.md) 把"处方药+全部补剂"清单给医生/药师核对；教练不承诺"绝对安全"。

## 六、误区澄清
- **误区："BCAA 是增肌神器，练后必喝"** → 单独 BCAA 不能净增加肌肉蛋白合成（缺其余 6 种 EAA）；相同亮氨酸下不优于完整蛋白 [151]。
- **误区："小苏打能日常提升训练表现"** → 只对 1–10 分钟高强度/反复冲刺场景有比赛日增益，日常高钠负荷无益且有胃肠风险 [152]。
- **误区："甜菜根汁喝了就能破 PR"** → 只对 ≥12 分钟耐力任务有 1–3% 级别的小增益；力量/短时无氧场景证据弱 [153]。
- **误区："泵感越强越增肌"** → 瓜氨酸带来的是血流/一氧化氮效应与主观"泵感"，不等同于肌肥大证据；增肌靠渐进负荷与蛋白 [154]。
- **误区："HMB 吃了不长肌肉是假的"** → 对年轻健康成人 RET 证据确实不支持显著 FFM/力量增益；对老年/失用人群证据更强——结论要按人群分开 [155][156]。
- **误区："每次训练都得喝电解质水"** → ≤1 小时常温力量训练白水足够；电解质只在长时/高温/大量出汗场景有明确价值 [158]。
- **误区："女性跑者直接买铁剂吃就行"** → 铁剂需要先查血清铁蛋白、由医生评估；过量铁有害，教练不指导剂量 [157]。
