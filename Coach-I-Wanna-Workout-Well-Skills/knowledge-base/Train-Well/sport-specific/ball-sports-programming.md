> 本文件为本主题的主要归属入口；交叉领域请按导读索引读取关联文件。

> 本文件供 AI 教练处理"**打球（篮球/羽毛球/网球/足球）和撸铁怎么搭配？一周怎么排期？打球当天还练不练力量？怎么防踝/膝/肩肘伤？赛季期和休赛期怎么调？**"这类问题。**本文件先明确立场：球类爱好者的力量训练不是"副业"，而是防伤、保持对抗与反复跑动跳跃能力的必修课；休赛期打基础（力量与肌肉量），赛季期用最小有效剂量维持（每周 1-2 次），力量课尽量排在球场课之前或独立日，避免同日疲劳叠加下勉强变向跳跃。** 依据：神经肌肉防伤 cluster RCT [213]、抗阻肥大立场 [3]、踝不稳平衡剂量 [177]、肩不稳非手术管理 [181]。

## 一、本主题回答哪些问题
1. 一周打 3-4 次球，力量训练怎么排进日程？
2. 打球当天还能不能练力量？先练什么、后练什么？
3. 篮球/足球（跑跳对抗）和羽毛球/网球（单侧旋转上肢）的力量重点有什么不同？
4. 怎么预防踝扭伤、膝前（髌股）痛、肩肘（网球肘/肩袖）损伤？
5. 赛季期力量还要不要练？练多少？
6. 休赛期/非赛季怎么打基础、补弱项？
7. 球类爱好者每周力量训练的最低有效剂量是多少？

## 二、核心结论（先给判断）
- **四类球类分两组需求**：篮球/足球 = 跑跳、急停变向、身体对抗、下肢离心与髋膝踝稳定；羽毛球/网球 = 单侧优势、肩肘上肢、旋转核心、髋部横向稳定与跨步落地控制。
- **力量/神经肌肉训练是防伤核心**：系统的神经肌肉+力量+平衡训练可显著降低球类运动损伤率，但效果高度依赖"规律依从"——断断续续做一次热身流程基本没用 [213]。
- **同日安排原则**：能异日分开最好；必须同日时"先力量、后球场"（力量课优先保证动作质量），避免先打 2 小时球再勉强冲大重量 [3]。
- **赛季期维持剂量**：每周 1-2 次力量、每肌群 4-6 组即可维持已有力量与肌肉量；赛季期不冲最大重量/最大容量，避免疲劳叠加 [3][148]。
- **休赛期打基础**：每周 2-3 次，渐进负荷，针对弱项（离心落地、髋外展/外旋、肩袖与肩胛稳定、单侧下肢力量）。
- **球场能力不能只靠撸铁**：变向、跳跃、挥拍技术需要专门练习；力量是地基，不是替代，跳跃与落地训练需另做系统练习。

## 三、适用人群与条件
- 每周打 1-4 次球的业余/俱乐部训练者；青少年参与者的抗阻训练安全剂量见 [61] Lloyd 青少年抗阻共识。
- 有明确伤史者（反复踝扭伤、髌股痛、肩不稳）：先按对应康复文件处理并回到无痛范围，再逐步加力量负荷。
- 几乎没进过健身房的新手：先学深蹲、铰链、推、拉等基础动作模式，再上专项力量（见 [执教技术与动作教学](../../Train-Well/coaching/coaching-techniques-and-instruction.md)）。
- 赛季期密集赛程/旅行多者：优先保证恢复与睡眠，力量降为维持剂量（见 [睡眠恢复与训练管理](../../Recover-Well/sleep-and-load/sleep-recovery-and-training-load.md)）。

## 四、决策规则（如果……则……）
- 如果"一周 3-4 次球场 + 想加力量" → 每周安排 2 次力量（放在球场日前一天或完全独立日），每次全身 30-45 分钟 [3][213]。
- 如果"今天先打球再想练力量" → 只做轻量稳定/核心/肩袖/髋外展练习，不冲负荷与 PR；优先保证下次球场状态。
- 如果"以篮球/足球为主" → 力量重点：深蹲/腿举（双侧）+ 保加利亚分腿蹲（单侧）+ 髋铰链（硬拉/臀推）+ 落地离心控制（原地跳落地、浅跳深）+ 核心抗旋（药球劈砍、死虫）[3]。
- 如果"以羽毛球/网球为主" → 力量重点：肩袖外旋与肩胛稳定（哑铃外旋、Y-T-W、面拉）+ 前臂屈/伸（网球肘防护）+ 旋转核心 + 髋外展与单侧下肢（防膝内扣、跨步落地）[181]。
- 如果"赛季中、赛程密" → 降到每周 1 次维持（每肌群 4 组），保留跳跃与下肢发力感，不追求新纪录 [3]。
- 如果"反复踝扭伤" → 加单腿平衡/本体感觉与落地纠正（见 [慢性踝不稳](../../Recover-Well/injuries-and-behavior/chronic-ankle-instability.md)，平衡剂量证据 [177]）。
- 如果"膝前痛（髌股）" → 减少深蹲到底与跳跃，加强股四头肌离心与臀中肌（见 [膝结构损伤](../../Recover-Well/injuries-and-behavior/knee-structural-injuries.md) [11]）。
- 如果"打球时肩痛/有要脱出感" → 停过头挥拍/扣杀动作，按肩不稳处理（见 [肩不稳与冻结肩](../../Recover-Well/injuries-and-behavior/shoulder-instability-and-frozen-shoulder.md) [181]）。
- 如果"跑步/折返后小腿胫骨痛" → 参考负荷递增规则处理跑量与跳量增量（[149] 跑步训练负荷规则）。

### 每周示例模板（力量 2 次 + 球场 3 次）
- 周一：力量 A（下肢双侧 + 推 + 核心抗旋）
- 周二：球场
- 周四：力量 B（单侧下肢 + 拉 + 肩袖/前臂）
- 周六：球场（主，强度高）
- 周日：球场或低强度有氧/休息
- 休赛期可把力量升到每周 3 次、每肌群每周 10-12 组，重点补弱项。

## 五、常见误区与证据限制
- **误区："打球本身就是训练，不用撸铁"** → 球场练的是专项耐力与技能，不提供力量、骨健康与防伤所需的渐进负荷；业余爱好者踝/膝/肩伤多与稳定、离心力量不足有关 [213][177][181]。
- **误区："赛季期还要猛练力量保持状态"** → 疲劳叠加反而增加伤病；赛季期维持剂量即可，基础在休赛期打。
- **误区："练力量会变僵、影响灵活性和挥拍"** → 渐进力量配合全幅度动作不会损害灵活性，反而改善落地与变向控制质量。
- **误区："防伤靠打球前随便热个身"** → 防伤流程（神经肌肉、平衡、落地纠正）需要规律、高依从地做，偶尔做一次无效 [213]。
- **证据限制**：神经肌肉防伤的高等级证据多来自青少年/精英足球人群（FIFA 11+ 类研究），业余羽毛球/网球的直接干预 RCT 较少；本文件以机制与间接证据外推，个体化调整 [213]。

## 六、证据限制与来源说明
- [213] Steffen 等为加拿大青少年女足 cluster RCT：高依从神经肌肉防伤组平衡改善、损伤率下降；外推到业余成人时需注意依从性与项目设计差异。
- 羽毛球损伤部位与生物力学特征来自流行病学综述（Pardiwala 2020），属描述性证据而非干预性证据。
