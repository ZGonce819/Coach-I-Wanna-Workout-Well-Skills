# Train Well：跑步与耐力专项训练（主题指南）
> [返回导读与主题索引](../../topic-index.md)
> 本文件为本主题的主要归属入口；交叉领域请按导读索引读取关联文件。

> 本文件供 AI 教练回答"我要跑步/跑马拉松，怎么安排训练"这类专项问题。核心依据为跑步相关损伤的训练错误综述与通用有氧处方（ACSM 2011）。跑伤康复（ITBS/跟腱/髌腱）见 [恢复与疼痛管理](../../Recover-Well/recovery-and-pain/recovery-and-pain-management.md) 与 [ITBS回归跑量](../../Recover-Well/injuries-and-behavior/itbs-running-return-and-load-evidence.md)。

## 一、本主题回答哪些问题
1. 新手想开始跑步，怎么从零起步？
2. 跑量怎么加才安全？"10% 规则"有依据吗？
3. 跑步计划里要不要安排力量训练？做什么？
4. 想提高成绩（5K/10K/半马/全马），怎么安排强度结构？
5. 跑者最容易伤在哪，怎么预防？

## 二、核心结论（先给判断）
- **跑步相关损伤大多与"训练错误"相关**：跑量、强度增加过快是主要可改变风险因素；新手跑者年损伤率约 20–80%（研究差异大），渐进加量是核心预防 [149]。
- **"10% 周增幅"是通行经验值而非硬性证据**：有研究显示新手跑者 10% 增幅与 24% 增幅的损伤风险无显著差异（HR≈0.8），真正危险的是单次/短期的负荷尖峰与过大跳跃；应关注"周负荷平稳、避免急性激增" [149]。
- **新手从"跑走结合"起步**：先建立每周 3 次、每次 20–30 分钟（跑走交替）的一致性，再逐渐延长跑段；心肺适应快于骨骼肌腱适应，"感觉能跑"不等于组织已适应 [149]。
- **力量训练是跑者的补强**：髋/核心/下肢力量训练可降低跑步损伤风险（证据中等），每周 2 次、无需大量即可获益；具体到 ITBS/跟腱见关联文件 [149]。
- **强度结构（进阶者）**：80/20 原则（约 80% 低强度 + 20% 高强度）是流行框架；对新手，先完成"量的一致"，再谈强度分布 [128,149]。

## 三、适用人群与条件
- 新手跑者（0–6 个月）：从跑走结合开始，本主题直接适用。
- 进阶跑者（5K 以上/备赛）：强度结构框架适用，具体计划结合目标赛事与恢复。
- 有跑伤史者：先过 [恢复与疼痛管理](../../Recover-Well/recovery-and-pain/recovery-and-pain-management.md)/[ITBS回归跑量](../../Recover-Well/injuries-and-behavior/itbs-running-return-and-load-evidence.md) 的重返标准，不直接套新手计划。
- 慢病人群（糖尿病/高血压/心脏）：跑步强度边界见 [慢病运动处方](../../Train-Well/chronic-conditions/chronic-conditions-and-exercise.md)，步行/跑走可能是更优起点。

## 四、决策规则（如果……则……）
- 如果"零基础想开始跑" → 每周 3 次跑走结合（如跑 1 分钟/走 2 分钟 × 8–10 循环），先保证 2–3 周一致性再增加跑段 [149]。
- 如果"加跑量" → 每周总跑量增幅控制在 10–15% 以内、不连续两周激进加量；单次跑不突然翻倍；出现持续疼痛/疲劳即回退一级 [149]。
- 如果"想防伤" → 加每周 2 次力量（分腿蹲/臀桥/单腿硬拉/核心），跑前动态热身、跑后低强度放松；不依赖"拉伸防伤" [149,140]。
- 如果"想提高 5K/10K 成绩" → 在稳定周跑量（≥20–25 km）基础上加每周 1 次间歇（如 5×1000m 目标配速 + 慢跑恢复）与 1 次长距离（占总跑量 25–30%）[128]。
- 如果"备赛半马/全马" → 长距离每周递增 10% 以内、每 3–4 周安排减量周；赛前 2–3 周减量；具体计划遵循渐进与恢复原则 [128,149]。
- 如果"跑步中出现新疼痛并持续" → 停止加量并筛查（[恢复与疼痛管理](../../Recover-Well/recovery-and-pain/recovery-and-pain-management.md)），疼痛部位对应 ITBS/跟腱/髌腱/腘绳肌主题处理 [149]。

## 五、可执行建议
- **新手 8 周起步模板（示例）**：第 1–2 周：3 次/周，跑走 20 分钟；第 3–4 周：3 次/周，25 分钟（跑段比例增加）；第 5–6 周：3 次/周，30 分钟 + 1 次力量；第 7–8 周：3–4 次/周，35–40 分钟，其中 1 次可连续跑 20 分钟以上 [149]。
- **跑者力量周模板**：每周 2 次、每次 20–30 分钟：分腿蹲 3×8–10/侧、臀桥 3×10–15、单腿硬拉 3×8–10、平板 3×30–45 秒、提踵 3×12–15；安排在轻松跑日或跑后 [149]。
- **给会员的解释**："跑步进步靠的是'每周都能跑'，不是'这周拼命跑'；骨骼和肌腱适应得比心肺慢，量加急了就是伤。" [149]
- **记录**：周跑量 + 疼痛日志（部位/强度/何时出现）；连续 2 周同一部位疼痛加重即减量并筛查 [149]。
- 装备与环境：跑鞋按磨损周期更换（约 500–800 km），初跑者选缓震跑鞋作为保护性起点（个体差异，不以品牌为处方）[149]。

## 六、例外、禁忌、停止条件和需要专业评估的情况
- 胸痛、晕厥、异常气促 → 停止并就医（与 [有氧处方](../../Train-Well/cardio/aerobic-and-conditioning-programming.md) 一致）[128,126]。
- 持续 2 周以上的同一部位疼痛、关节肿胀、明显跛行 → 停止加量并走 [恢复与疼痛管理](../../Recover-Well/recovery-and-pain/recovery-and-pain-management.md) 的转介流程。
- 慢病人群（心脏/糖尿病）跑步前先过 [运动前筛查](../../Recover-Well/screening-and-injury-spectrum/pre-exercise-screening-and-risk-stratification.md) 与 [慢病运动处方](../../Train-Well/chronic-conditions/chronic-conditions-and-exercise.md) 的强度边界。
- 天气极端（高温/污染/冰面）时调整训练环境与强度；不"硬跑"。

## 七、常见误区与证据限制
- **误区："跑步伤膝盖"** → 中等剂量跑步与膝骨关节炎风险增加无关（甚至有保护作用）；不合理的加量才是风险 [149]。
- **误区："跑前必须拉伸防伤"** → 静态拉伸防伤证据弱；动态热身与渐进负荷更重要 [149,140]。
- **误区："每周必须 +10% 否则不安全"** → 10% 是经验值，核心是避免负荷尖峰与过快跳跃 [149]。
- **证据限制**：
  1. 跑步损伤研究在损伤定义、跑量测量上异质，损伤率区间很大 [149]。
  2. 力量训练防伤证据多为中等质量，最佳剂量未定 [149]。
  3. 80/20 强度分布来自精英/亚精英跑者数据，业余跑者外推需谨慎 [128]。
