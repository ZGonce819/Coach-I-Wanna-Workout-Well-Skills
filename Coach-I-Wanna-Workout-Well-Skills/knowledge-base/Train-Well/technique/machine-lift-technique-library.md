## 二、核心结论（先给判断）
- **固定器械的核心优势是"轨迹固定、疲劳管理好、可以更接近力竭"，代价是"稳定肌参与少、个性化调整空间小"**。器械适合新手建立动作模式、疲劳组后追加容量、特定肌群精准刺激；自由重量适合发展整体力量和稳定肌。两者互补，不必二选一 [39][3]。
- **脚位/握位调整是器械动作的核心变量**：同一台腿举机，脚高偏臀/腘绳，脚低偏股四，脚宽偏内收/臀，脚窄偏股四外侧。调整目的是"改变力矩和肌肉长度-张力关系"，不是"练到不同位置" [45][48]。
- **器械不是"安全保证"**：固定轨迹不等于适合每个人的关节角度。调整座椅高度、把手位置、行程范围，使动作在无痛、可控范围内完成；疼痛时先调位置减重，不硬撑 [39]。
- **腿屈伸/腿弯举等单关节器械是"辅助动作"，不是主项**：重量选择以"目标肌群主导、无代偿"为准，不追求大重量；大重量单关节动作更容易出现代偿和关节压力 [39]。
- **龙门架（绳索）是"半自由半器械"**：轨迹由你控制、阻力始终存在，兼具自由重量的功能性和器械的持续张力；是练中缝、后束、手臂等细节肌群的高效工具 [45][48]。
- **器械重量读数 ≠ 实际负荷**：不同品牌器械的力臂、凸轮曲线、配重片重量差异大；同一动作"这台60kg"和"那台60kg"的实际刺激可能差很多。以"次数-RIR-发力感"为调整依据，不跨器械比较重量数字 [39]。

## 三、适用人群与条件
- 本文件适用于**健康成人**使用健身房固定器械进行训练的技术调整与动作选择。
- **需要转介/降级的情况**：动作时出现锐痛、关节卡顿、麻木 → 先按 [Recover Well](../../Recover-Well/recovery-and-pain/recovery-and-pain-management.md) 处理；器械调整后仍代偿明显 → 考虑换自由重量或降级动作。
- **新手建议**：先从器械学动作模式（轨迹固定、容易找发力感），再逐步加入自由重量；不要一上来就冲大重量自由重量 [39]。

## 四、决策规则（如果……则……）
### 1. 腿举/倒蹬机
- 如果问"腿举和哈克深蹲先练哪个" → 两者都是下肢复合动作；腿举靠背支撑、核心压力小，适合新手入门或疲劳后追加容量；哈克深蹲更接近深蹲模式、核心参与更多。新手可从腿举开始学下肢发力模式 [39]。
- 如果想侧重股四头肌 → 脚位放低（踏板中下部）、双脚与肩同宽或略窄、下蹲时膝盖尽量往前；注意不锁膝 [45]。
- 如果想侧重臀/腘绳肌 → 脚位放高（踏板上部）、双脚略宽、下蹲时臀部向后推、膝盖角度变化小；顶峰时夹臀 [45]。
- 如果想侧重内收肌/臀中肌 → 双脚站距宽（约1.5倍肩宽）、脚尖外展30-45°；类似相扑深蹲的感觉 [45]。
- 如果问"能不能大重量腿举" → 腿举重量通常远大于深蹲，但风险也随之增加：腰部离开靠背、膝盖内扣、底部弹震都是危险信号。控制范围：全程靠背贴紧、不锁膝、不弹震 [39]。
- 如果膝前痛 → 减小行程（不要蹲太深）、脚位略高、减重；持续不适转 Recover Well [11]。

### 2. 哈克深蹲机
- 如果问"哈克深蹲和自由深蹲区别" → 哈克深蹲轨迹固定、杠铃路径垂直、身体前倾少，股四头肌参与更集中；核心稳定需求低于自由深蹲。适合强化股四头、膝盖问题者（轨迹可控）[39]。
- 如果想侧重臀 → 脚位前移、身体前倾更多；想侧重股四 → 脚位后移、身体直立。
- 如果弯腰/腰部离开靠背 → 减重；靠背支撑的意义就是保护腰部，弯腰等于白用 [39]。

### 3. 坐姿推胸机 vs 器械卧推
- 如果问"两个推胸动作选哪个" → 坐姿推胸有靠背支撑、上半身稳定，适合先练胸肌发力、疲劳组追加；器械卧推（平板/上斜）轨迹更自由、肩胛活动度更大，更接近自由卧推的模式。两者都练胸，侧重点不同 [39]。
- 如果肩前侧痛 → 调整把手位置：把手过低（肩以下）或过宽（比肩宽很多）都会增加肩前压力；把手对齐中胸、肘与身体约45-60°更安全 [52]。
- 如果"总用肩代偿、胸没感觉" → 先减重，想象"用肘去碰对面的墙"而不是"用手推"；顶峰时夹胸1秒；检查肩胛是否后缩下沉 [48]。
- 如果上胸薄弱 → 选上斜器械卧推（角度30-45°），不选平板坐姿推胸。

### 4. 腿屈伸机
- 如果问"腿屈伸伤不伤膝" → 技术正确、重量适中的腿屈伸不损伤健康膝关节；大重量+末端猛甩才是风险。控制：缓慢控制（2-3秒向心、1-2秒离心），不锁膝 [39]。
- 如果想侧重股直肌（大腿前侧上部） → 坐姿时躯干稍后仰、脚尖朝前；想侧重股外侧/内侧 → 脚尖内扣/外旋调整（轻微，不要过度）[45]。
- 如果膝盖前侧不适 → 减小行程（不要完全伸直到锁死）、减重；髌股疼痛者谨慎使用 [11]。
- 重量选择：这是单关节辅助动作，重量以"最后2次还能控制动作不变形"为准，不追求大重量。

### 5. 俯卧腿弯举机
- 如果"练不到腘绳、总用腰抬" → 先调整髋部位置：髋部折痕对齐器械转轴；腹部收紧，不要挺胸塌腰；顶峰时（脚跟靠近臀部） squeeze 腘绳肌1秒 [45]。
- 如果想侧重腘绳肌外侧/内侧 → 脚尖外八/内八微调（轻微）；大多数人脚尖朝前即可。
- 如果小腿也紧张 → 勾脚尖 vs 绷脚尖会改变小腿参与；勾脚尖时比目鱼肌参与更多，想孤立腘绳可稍微绷脚尖 [45]。
- 如果腰代偿明显 → 减重到能控制躯干不动；不要为了重量把整个上半身抬起来。

### 6. 侧平举器械/哑铃侧平举
- 如果问"哑铃还是器械侧平举好" → 器械侧平举轨迹固定、阻力曲线均匀（在最有力的位置阻力最大），更容易控制斜方肌代偿；哑铃侧平举在最低位置阻力为零，需要更强的肩胛控制。新手从器械入门更容易找三角中束发力感 [39]。
- 如果"总用斜方肌耸肩" → 减重；想象"用肘去碰天花板"而不是"用手举"；不要举过肩（手肘不要超过肩膀高度）；先做肩胛下沉再抬手 [48]。
- 重量选择：侧平举是小肌群动作，重量通常很小（哑铃2.5-5kg起步）；能做15次以上还能保持姿势的重量才合适。大重量借力反而练斜方肌。

### 7. 龙门架绳索动作（夹胸/面拉/下压/飞鸟）
- 如果想练胸中缝 → 龙门架夹胸（从下往上或平举）比蝴蝶机更有拉伸感：起点时胸部有拉伸、顶峰时夹胸。轨迹由你控制，可以定制行程 [45]。
- 如果想练后束 → 反向蝴蝶机飞鸟 vs 龙门架面拉：反向蝴蝶机更孤立后束，面拉同时练后束+外旋肌群+肩袖，对肩健康更友好。肩袖弱的人优先面拉 [52]。
- 如果做绳索下压练三头 → 直杆 vs 绳索：直杆更偏外侧头，绳索（把手分开）更偏长头。大重量容易用肩前倾代偿，减重控制 [45]。
- 龙门架的优势：**全程张力**——自由重量在最低点（如飞鸟初始位置）阻力为零，绳索全程有阻力。这是绳索动作的核心价值 [39]。

## 五、安全边界与停止条件
- **立即停止并转介的信号**：锐痛、关节卡顿、麻木、肢体无力、头晕胸痛（见总控安全优先）。
- **控制失败即减重**：动作变形、身体摇晃、重量转移（器械配重片晃动）→ 减到可控，不"硬抗"。
- **器械调整优先于硬练**：座椅高度、把手位置、脚位不对时，先调器械再减重，不要在错误角度硬练 [39]。
- **大重量单关节动作不做力竭组**：腿屈伸、侧平举这类动作力竭时代偿风险高，留1-2次余力即可 [39]。

## 六、误区澄清
- **误区："固定器械绝对安全，随便练"** → 固定轨迹不等于适合每个人的关节角度；不调整座椅高度、大重量代偿、底部弹震一样会受伤 [39]。
- **误区："腿举重量越大越好"** → 腿举重量数字好看但实际负荷因器械而异；腰部离开靠背、锁膝、膝盖内扣都是危险信号，不追求重量数字 [39]。
- **误区："腿屈伸专门伤膝盖"** → 技术正确、重量适中的腿屈伸不损伤健康膝关节；大重量+猛甩才是风险。髌股疼痛者需谨慎 [39][11]。
- **误区："器械练的肌肉不如自由重量"** → 增肌刺激来自机械张力，在同等容量和接近力竭的前提下，器械和自由重量差异不大；器械甚至在疲劳管理上有优势 [3]。
- **误区："侧平举举越高越练肩"** → 举过肩反而增加肩峰撞击风险；手肘与肩同高或略低即可，重点是三角中束发力 [52]。

## 七、证据限制与来源说明
- 器械动作技术证据多为**生物力学分析与教科书共识**（NSCA [39][115]、运动解剖教材 [45][48]），属于"技术共识级"而非"疗效级"。
- 不同品牌器械的轨迹、力臂、凸轮曲线差异大，本文件的描述基于"典型器械"，具体调整以实际器械为准。
- 器械重量读数因品牌差异大，不跨器械比较重量数字；以"次数-RIR-发力感"为调整依据 [39]。
- 引用编号 [293]–[298] 为本文件新增；[39][45][48][52][3][11][159] 为复用既有编号。

| 器械动作 | 核心调整变量 | 常见代偿 | 主要降级 | 主要升级 |
|---|---|---|---|---|
| 腿举/倒蹬 | 脚高低=股四vs臀腘；脚宽窄=股四vs内收 | 腰离开靠背、锁膝、弹震 | 减小行程、减重 | 单腿、暂停 reps |
| 哈克深蹲 | 脚前后=股四vs臀；身体直立度 | 弯腰、腰离开靠背 | 减小行程 | 单腿、加重量 |
| 坐姿推胸 | 把手高度=上胸vs中胸；肘角 | 肩前耸、肩胛松 | 减重、调把手位置 | 加重、递减组 |
| 器械卧推 | 上斜角度=上胸vs中胸；握距 | 肩前痛、杠晃 | 半程、减重 | 加重、暂停推 |
| 腿屈伸 | 脚尖方向=股四各头；行程 | 锁膝猛甩、腰抬 | 减小行程 | 加重、慢速离心 |
| 俯卧腿弯举 | 髋部转轴对齐；躯干固定 | 腰代偿抬身、小腿发力 | 减重、躯干固定 | 加重、单腿 |
| 侧平举（器械/哑铃） | 重量小、手肘不过肩 | 斜方肌耸肩、甩动量 | 减重、找发力感 | 加微小重量 |
| 龙门架夹胸/飞鸟 | 轨迹自定、全程张力 | 肩前代偿、甩动 | 减重、控制速度 | 加重、顶峰收缩 |
| 龙门架面拉/下压 | 把手选择=不同头侧重 | 肩前倾代偿 | 减重、控制 | 加重、超级组 |
