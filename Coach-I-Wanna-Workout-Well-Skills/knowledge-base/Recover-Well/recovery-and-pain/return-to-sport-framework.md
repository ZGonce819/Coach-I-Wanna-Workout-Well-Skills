# 伤后重返运动总框架（主题指南）
> [返回导读与主题索引](../../topic-index.md)
> 本文件为本主题的主要归属入口；交叉领域请按导读索引读取关联文件。

> 本文件供 AI 教练在会员**从损伤中恢复、准备回到训练/运动**时使用：如何把"能动了"推进到"能安全回去了"。它把踝、膝、肩、腘绳肌等各损伤文件里的零散回归标准统一到一个通用阶段框架。**本文件先明确立场：重返运动不是"时间到了"或"不痛了"的单点决定，而是"组织健康 + 活动风险 + 风险容忍"三要素的综合判断（StARRT 框架）；教练做渐进执行与监测，最终放行（尤其术后/高风险运动）由康复/医疗团队负责。** 依据：重返运动决策框架 [180]、ACL 回归标准 [179]。
>
> **适用边界：适用于肌肉骨骼损伤后的回归训练（扭伤、拉伤、肌腱病、术后已获医疗放行阶段）。急性期、未确诊、红旗症状 → 先按对应损伤文件处理；本框架不替代专业放行。**
---
## 一、本主题回答哪些问题
1. 伤好了多久能回去练？
2. "不痛了"就能恢复训练吗？
3. 回归训练分几个阶段？每阶段做什么？
4. 怎么判断自己"够格"回归某项运动？
5. 不同运动（跑步/球类/举铁）要求一样吗？
6. 回归后怎么监控会不会再伤？
7. 教练和医生的放行职责怎么分？
---
## 二、核心结论（先给判断）
- **三要素框架（StARRT）**：①组织健康（愈合状态、疼痛/肿胀、力量、ROM）；②活动风险（该运动对组织的需求：冲击、变向、角度）；③风险容忍（运动员的价值与情境：赛季、年龄、收益）。三者共同决定回归时机 [180]。
- **回归是分级渐进，不是开关**：经典路径为 活动度/无痛 → 力量/耐力 → 基础运动（跑、跳、变向）→ 专项模拟 → 比赛/全量；每级达标才进下一级 [180][179]。
- **时间不是标准**：ACL 重建等大伤后 ≥9–12 个月仅为必要条件，还需功能对称（力量 LSI ≥90%）、心理准备、专项测试 [179]。
- **需求决定标准**：高冲击变向运动（篮球/足球/滑雪）标准最严；低冲击（游泳/骑车/一般力量）标准宽松。同一损伤两种运动可以不同时回归 [180]。
- **回归后监控**：症状反应（疼痛/肿胀/次日反应）、负荷渐进（10% 原则类）、功能保持；出现再伤信号 → 降级或转介 [180][179]。

## 三、适用人群与条件
- 各部位损伤后的回归训练者；作为 [踝不稳](../../Recover-Well/injuries-and-behavior/chronic-ankle-instability.md)、[膝结构损伤](../../Recover-Well/injuries-and-behavior/knee-structural-injuries.md)、[肩不稳](../../Recover-Well/injuries-and-behavior/shoulder-instability-and-frozen-shoulder.md)、ITBS、腘绳肌等文件的**通用上层框架**。
- 术后回归需先获手术团队/康复师阶段性放行；教练执行下一级训练。
- 红旗（神经症状、未消退肿胀、新畸形）→ 停止并转介。
---
## 四、决策规则（如果……则……）
### 分级渐进
- 如果会员问"能不能练了" → 对照当前阶段：先无痛活动度与基础负荷 → 力量恢复 → 运动模式（跑/跳/变向）→ 专项 → 全量；未过前级不进后级 [180][179]。
- 如果"不痛了" → 不痛只是进入下一级的条件之一；还需力量/控制/心理达标 [179]。
- 如果会员想直接回球场 → 按该运动需求评估（变向/冲击等级）；高需求运动必须过专项测试（跳跃/变向/模拟）[180][179]。

### 三要素判断
- 如果组织健康未达标（持续疼痛/肿胀、力量 LSI <90%）→ 不回归，继续当前级康复 [180][179]。
- 如果组织健康达标但心理恐惧/信心低 → 延迟高强度回归，加入心理准备与渐进暴露 [179]。
- 如果会员是高需求运动+低风险容忍情境（如赛季末、可接受风险）→ 记录知情决定，仍以渐进方式回归 [180]。

### 监控与转介
- 如果回归训练中出现持续性疼痛/肿胀（如训练后次日加重）→ 降级一档，观察 1–2 周；不缓解 → 评估 [180]。
- 如果术后/严重损伤，任何回归决策 → 与康复/医疗团队对齐，教练不单独放行 [180][179]。

## 五、误区澄清
- **误区："不痛=可以回去了"** → 不痛是必要条件非充分条件；力量/控制/心理未达标仍高风险 [179]。
- **误区："术后 X 个月=恢复"** → 时间是必要条件；功能与专项测试才是放行依据 [179]。
- **误区："能慢跑就能打球"** → 不同运动需求差异大；按目标运动的专项测试评估 [180]。
- **误区："回归是医生一句话"** → 是团队（医疗+康复+教练+运动员）渐进决策；教练负责执行与监测 [180]。
- **误区："回归后就不会再伤"** → 再伤风险持续存在；回归后监控与负荷管理是康复的一部分 [179][180]。

## 六、证据限制与来源说明
- StARRT 框架 [180] 为临床决策框架（专家共识级）；具体阈值（LSI 90%）来自 ACL 文献 [179]，其他损伤类推时保留个体化。
- 分级渐进路径为运动康复通用原则，各损伤的具体阶段划分见对应主题文件。
- 引用编号 [180][179] 为本文件新增；[163]（sRPE 监控）、[39][126] 为复用既有编号。

| 阶段 | 内容 | 达标判据（示例） |
|---|---|---|
| 1 基础 | 无痛 ROM、低负荷力量 | 无痛、无肿胀反应 |
| 2 力量 | 患侧力量恢复、耐量 | LSI ≥90%（大伤标准） |
| 3 运动模式 | 跑/跳/变向基础 | 动作质量+无痛 |
| 4 专项 | 模拟目标运动 | 专项测试通过 |
| 5 全量 | 完整训练/比赛 | 医疗+康复放行 |
