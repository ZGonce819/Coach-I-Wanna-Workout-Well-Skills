# 训练成瘾与男性肌肉上瘾（主题指南）
> [返回导读与主题索引](../../topic-index.md)
> 本文件为本主题的主要归属入口；交叉领域请按导读索引读取关联文件。

> 本文件供 AI 教练处理"**不练就难受/停不下来是不是成瘾、一天不练就焦虑正常吗、过度追求肌肉和低体脂是不是病、男性也会有身材焦虑吗、什么时候该转介**"这类问题：强迫性训练与肌肉上瘾（muscle dysmorphia）的识别线索与教练边界。**本文件先明确立场：规律训练带来的自律与偶尔的"想练"不等于成瘾；真正需要警惕的是"失控感+戒断痛苦+功能损害"——训练开始挤占睡眠/工作/社交、受伤仍练、错过训练极端崩溃，并伴随对体型的强迫性关注。教练不做诊断，但承担识别、停止强化、温和转介的责任；本文件是既有《身材焦虑与进食障碍：教练边界》的"男性/训练行为侧"扩展——进食障碍（节食/暴食/体重执念）侧看既有文件，本文件聚焦训练成瘾与肌肉上瘾。** 依据：运动成瘾量表 EAI [235]、肌肉上瘾系统综述与 meta [236]、进食障碍识别 [202]、LEA/RED-S [186][203]。
>
> **适用边界：本文件不做诊断；仅做筛查/训练调整/教育；红旗条件（失控、自伤、危机、功能严重受损）必须转介心理/医疗/危机支持；不承诺"练够多少就一定好"。**

## 一、本主题回答哪些问题
1. 一天不练就浑身难受、焦虑，这是训练成瘾吗？
2. 受伤了还非要练、错过训练课就崩溃，正常吗？
3. 男的也会"身材焦虑"吗？一直嫌自己不够壮是什么问题？
4. 什么是肌肉上瘾（muscle dysmorphia）？和普通追求肌肉有啥区别？
5. 训练成瘾和过度训练、LEA/RED-S 是什么关系？
6. 教练发现会员有这些信号，该怎么说？什么时候必须转介？
7. 会员提到偷偷用药/合成代谢物质，教练怎么处理？
8. 转介之后，教练还能继续带他训练吗？

## 二、核心结论（先给判断）
- **区分"自律"与"成瘾"**：规律、可持续、能灵活调整的训练是健康行为；训练成瘾的核心不是"练得多"，而是**失控感与功能损害**——想停停不下来、训练挤占生活、因训练与他人冲突、受伤/生病仍练、错过训练出现强烈的戒断式情绪（焦虑、烦躁、愧疚）[235]。
- **EAI 六维识别线索（教练只作筛查线索，不做诊断）**：运动成瘾量表围绕**耐受性（越练越多才够）、戒断（停训烦躁/焦虑/低落）、失控（想减减不下来）、时间占用（大量时间用于练/恢复/想练）、冲突（挤占工作/学习/社交/家庭）、复发（戒断后很快又回到旧模式）**六个维度 [235]。教练观察到越多维度同时出现，越要提高警惕。
- **强迫性训练的红旗行为**：带伤/带病坚持原定负荷、因训练计划严格到无法灵活调整、训练明显挤占睡眠与工作、隐瞒真实训练量/补剂使用、错过一节课就极端崩溃并急于"补回来"（见 [睡眠恢复与训练管理](../../Recover-Well/sleep-and-load/sleep-recovery-and-training-load.md) 的过度训练识别）。
- **肌肉上瘾（muscle dysmorphia）**：属于身体意象相关问题，核心是**对"自己不够大/不够干"的先占观念**——反复照镜子/称重/量围度、对体型缺陷过度关注、训练/饮食/补剂高度强迫、回避暴露身体的社交与亲密关系、为"干"与"大"采取极端饮食甚至滥用合成代谢物质 [236]。系统综述与 meta 显示，肌肉上瘾症状在健美者与抗阻训练者中较普通训练者更普遍，且与强迫特质、合成代谢物质使用相关 [236]。
- **男性身体意象风险是真实的**：肌肉上瘾常被称作"反厌食症"或"巨兽症"，主要见于男性、健身/健美/力量人群；男性同样会因体型痛苦，只是表现为"嫌自己小/不够干"而非"嫌自己胖" [236]。
- **与 LEA/RED-S 的关联**：强迫训练叠加极端饮食（为"干"而长期低能量）可致低能量可用性，女性月经紊乱、男性激素与表现受损、骨健康下降——这是身体健康红旗，不是"状态好" [186][203]。
- **教练边界**：不诊断、不开药、不评判羞辱；把目标从"更壮/更干"翻译为功能向（力量、能量、动作质量）；出现红旗温和转介心理/医疗；自伤/危机信号立即转危机支持（同 [损伤心理与行为支持](../../Recover-Well/injuries-and-behavior/common-injuries-and-behavior-support.md)）[202]。

## 三、适用人群与条件
- 健身/力量/健美人群中表现出强迫性训练、体型先占观念、极端饮食或补剂执念的会员；尤其男性、备赛/冲脂人群。
- 与既有文件分工：**进食障碍侧（节食/暴食/体重焦虑/催吐泻药）→ 看 [身材焦虑与进食障碍：教练边界](../../Recover-Well/injuries-and-behavior/body-image-and-eating-disorder-boundaries.md)；本文件聚焦"训练行为停不下来"与"嫌自己不够壮/不够干"的肌肉上瘾侧**。
- 已确诊相关心理问题或正在治疗者：训练只配合治疗团队允许的范围，不设体型/体重目标。
- 青少年：风险更高且需家长/专业介入，见 [青少年与长期效应](../../Train-Well/youth-and-long-term/youth-and-long-term-effects.md)。
- 本文件不处理：训练计划本身的设计（见 [训练方案与进阶](../../Train-Well/training/training-programming-and-progression.md)）、伤病康复流程（见 [损伤心理与行为支持](../../Recover-Well/injuries-and-behavior/common-injuries-and-behavior-support.md)）。

## 四、决策规则（如果……则……）
### 分诊与转介
- 如果会员出现多项 EAI 线索（耐受+戒断+失控+冲突同时存在）→ 视为高风险信号，停止"再加量"类建议，温和说明"这些训练模式值得和专业人士聊聊"，建议心理/运动心理方向评估 [235][202]。
- 如果会员带伤/带病仍坚持原负荷、或因错过训练极端痛苦并强行补量 → 立即下调训练、强调恢复优先；反复出现则转介 [235][202]。
- 如果会员表达自伤、自杀念头或危机信号 → 不继续谈训练，立即引导危机支持/紧急求助（同 [身材焦虑与进食障碍：教练边界](../../Recover-Well/injuries-and-behavior/body-image-and-eating-disorder-boundaries.md) 的危机流程）[202]。
- 如果会员长期极端低能量+强迫训练+表现/激素/月经异常 → 评估 LEA/RED-S，转医疗/营养 [186][203]。
- 如果会员透露使用或打算使用合成代谢/不明补剂 → 不提供使用指导，明确健康风险，转医疗/专业评估 [236]。

### 日常沟通与训练调整
- 如果会员说"一天不练就焦虑/愧疚" → 正常化偶尔的想念训练，同时温和探询：停训一天会怎样？是否影响了睡眠/工作/社交？用 EAI 线索自查 [235]。
- 如果会员反复强调"还不够大/还不够干"、频繁照镜量围度、回避社交 → 提示这可能是身体意象先占，把对话转向功能进步（力量、能量、动作），不继续加码体型目标 [236][202]。
- 如果会员的训练计划僵化到无法因疲劳/伤病调整 → 教练主动引入"减量周/灵活调整"，示范训练是可协商的，不是必须完成的强制任务 [235]。
- 如果会员想"减一点量试试"但非常恐惧 → 支持其尝试 1 周减量并记录情绪与表现，把"少练也不会垮"变成可体验的证据 [235]。
- 转介后 → 教练仍可提供**非目标化的功能训练**（力量、能量、动作质量），但不再设围度/体脂/备赛目标，也不参与药物/极端饮食讨论 [202][236]。

### 话术原则
- 如果会员自嘲"我就是练上瘾了" → 不附和、不把成瘾当优点炫耀；用好奇而非评判的语气了解其停训反应 [235]。
- 如果会员把自我价值完全绑定在体型/训练上 → 温和拓宽评价维度（健康、关系、工作、兴趣），不羞辱 [202][236]。

## 五、常见误区与证据限制
- **误区："练得多、自律强 = 优秀，成瘾是夸他"** → 把强迫性训练当正面标签会强化问题；失控感与功能损害才是关键 [235]。
- **误区："男的只会追求强壮，不可能有身材焦虑"** → 男性身体意象问题真实存在，肌肉上瘾就是典型表现，常被忽视 [236]。
- **误区："错过训练痛苦说明热爱，正常"** → 偶尔想念正常；错过一节课就崩溃、并以补偿性过量训练缓解，是戒断式反应线索 [235]。
- **误区："教练只管带练，心理问题与我无关"** → 识别与温和转介是专业责任；忽视红旗可能延误干预 [202][235]。
- **误区："转介=我不能再带他了"** → 转介后仍可提供安全、非体型目标的功能训练 [202]。
- **证据限制（诚实标注）**：
  1. EAI [235] 是筛查工具而非诊断标准；教练用其维度做"要不要转介"的线索，不能据此贴"成瘾"标签。
  2. 肌肉上瘾 meta [236] 主要纳入健美者/抗阻训练者，患病率与症状关联多来自横断面/观察研究，因果方向不明确。
  3. 男性身体意象的精确患病率证据有限，不同样本差异大；本节给"风险现实"而非"发病率"。
  4. 本文件不提供任何精神科诊断标准或治疗方案，诊断与治疗属心理/医疗职责。

## 六、证据限制与来源说明
- [235] Griffiths/Szabo/Terry 2005 为 EAI 量表的简要筛查工具论文（Br J Sports Med），面向健康从业者快速识别；六维框架用于教练筛查线索，非临床诊断。
- [236] Mitchell 2017 Sports Med 为肌肉上瘾症状在健美者/抗阻训练者中的系统综述与 meta，显示症状更普遍并与强迫特质/合成代谢物质使用相关；证据以横断面为主。
- [202] NICE 进食障碍指南提供红旗识别与转介框架；[186][203] 提供 LEA/RED-S 与低能量可用性生活背景。
- 教练角色边界：本文件所有"识别线索"均为触发转介/调整的信号，不构成诊断；任何确诊与治疗由专业人员完成。

| 信号 | 教练动作 | 转介 |
|---|---|---|
| 停训焦虑/愧疚、想减减不下来 | 用 EAI 线索自查，示范灵活减量 | 多维度并存时心理评估 |
| 带伤带病坚持原负荷、错过课崩溃补量 | 立即下调、恢复优先 | 反复出现转介 |
| 嫌自己不够壮/干、强迫照镜量围度、回避社交 | 转功能目标，不加码体型 | 严重先占时心理评估 |
| 极端低能量+强迫训练+月经/激素/表现异常 | 停激进方案 | 医疗+营养（LEA/RED-S） |
| 合成代谢物质使用/意图 | 不指导使用，说风险 | 医疗 |
| 自伤/危机信号 | 停止训练话题 | 立即危机支持 |

- 引用编号 [235][236] 为本批新增；[186][187][202][203] 为复用既有编号。
