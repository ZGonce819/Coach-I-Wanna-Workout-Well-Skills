# 膝部结构损伤边界：半月板与 ACL（主题指南）
> [返回导读与主题索引](../../topic-index.md)
> 本文件为本主题的主要归属入口；交叉领域请按导读索引读取关联文件。

> 本文件供 AI 教练处理"**膝部结构损伤**"相关场景：半月板损伤（尤其退变性）、ACL 撕裂/重建术后回归训练。**本文件先明确立场：多数退变性半月板损伤首选非手术（运动治疗）而非手术；ACL 重建后回归运动是漫长的分阶段过程，标准是功能+时间+心理的综合判断，不是"术后 X 个月就能打"；教练在术后康复的医学框架内做训练执行与回归监测，不决定手术与最终放行。** 依据：ESSKA-AOSSM-AASPT 2024 半月板康复共识 [182]、ACL 回归标准综述 [179]。
>
> **适用边界：急性膝外伤（肿胀、无法负重、绞锁、明显不稳）→ 先医疗评估；ACL/半月板术后 → 遵循手术团队方案。** 本文件不覆盖骨折、多韧带损伤。

## 一、本主题回答哪些问题
1. 半月板损伤是不是一定要手术？
2. 退变性半月板损伤怎么练？
3. ACL 术后多久能跑步/打球？
4. ACL 术后回归运动要满足什么条件？
5. 膝内有"卡住/绞锁"感是什么信号？
6. 术后康复能不能自己练？
7. 深蹲伤膝盖吗？有结构损伤还能练腿吗？
---
## 二、核心结论（先给判断）
- **半月板（尤其退变性）**：
  - 一线处理是运动治疗+活动调整；保守与手术在多数退变性撕裂中结局相当（10 年随访：运动治疗与关节镜部分切除术在疼痛/功能/OA 进展上无实质差异）[182]。
  - 康复要素：无痛 ROM、渐进膝髋力量（股四头肌为核心）、神经肌肉训练；血流量限制训练在无禁忌时可辅助早期增力 [182]。
  - 机械症状（绞锁、反复卡住）或保守无效 → 转骨科评估（手术指征）[182]。
- **ACL 重建后回归**：
  - 回归是"标准组合"而非时间表：时间（通常 ≥9–12 个月）+ 功能（患侧 LSI ≥90% 的力量/跳跃测试）+ 心理准备（ACL-RSI 类量表）+ 运动专项渐进 [179]。
  - 过早回归高风险：20 岁以下高冲击运动人群，回归后再伤率约 1/5（对侧与移植物）[179]。
  - 教练角色：执行术后康复计划（医疗方制定）、监测症状与功能、逐步引入运动专项、不单独放行 [179]。
- **"深蹲伤膝盖"**：对健康与多数术后已回归阶段者，渐进深蹲有助力量恢复；急性期与特定术后阶段按方案执行 [182][179]。
---
## 三、适用人群与条件
- 半月板：退变性撕裂成人（40+ 常见，常伴轻度 OA）、创伤性撕裂保守期。
- ACL：重建术后训练者、非手术管理的撕裂者。
- 红旗：急性绞锁/卡住、无法承重、术后发热/伤口异常、突发剧痛肿胀 → 转介；不自行处理。
---
## 四、决策规则（如果……则……）
### 半月板
- 如果退变性半月板撕裂（无机械症状）→ 推荐运动治疗：ROM+股四头肌/髋力量+神经肌肉训练；活动调整（低冲击有氧如骑车/游泳）；不急着手术 [182]。
- 如果膝"卡住/绞锁"或反复肿胀影响生活 → 骨科评估（手术指征）[182]。
- 如果伴明显 OA → 力量训练仍推荐（减痛、改善功能）；负荷以耐受为度（见 [慢病运动处方](../../Train-Well/chronic-conditions/chronic-conditions-and-exercise.md)）[182]。

### ACL 术后回归
- 如果术后早期（0–6 个月）→ 严格按手术团队方案；教练执行 ROM/力量/步态阶段目标，不自行加量 [179]。
- 如果到回归评估阶段 → 检查时间（≥9–12 个月）、力量对称（LSI ≥90%）、跳跃测试、心理准备、专项渐进；未达标准 → 继续强化，不催促 [179]。
- 如果 20 岁以下/高冲击运动（篮球/足球/滑雪）→ 更严格标准与更长时间；明确"早回归=高再伤风险" [179]。
- 如果会员问"能不能去打球了" → 先跑回归评估标准；由康复/手术团队放行 [179]。

### 一般训练
- 如果会员问"深蹲会不会加重" → 结构损伤本身不是深蹲禁忌；按阶段与症状（无痛范围、控制良好）渐进 [182][179]。
- 如果训练中出现绞锁/明显不稳/术后异常肿胀 → 停止并转介 [182][179]。

## 五、误区澄清
- **误区："半月板撕裂必须手术"** → 退变性撕裂首选保守；多数保守与手术结局相当 [182]。
- **误区："ACL 术后一年肯定能打"** → 时间只是条件之一；未达标回归再伤率高 [179]。
- **误区："术后康复就是回家躺着"** → 主动康复（ROM/力量/神经肌肉）是结局决定因素 [179][182]。
- **误区："深蹲废膝盖"** → 渐进力量训练对多数膝问题是治疗而非病因 [182]。
- **误区："教练说能上就能上"** → 回归放行需手术团队/康复专业综合判断 [179]。

## 六、证据限制与来源说明
- 半月板共识 [182] 为 2024 国际共识（ESSKA-AOSSM-AASPT），推荐等级多为 GRADE B；10 年随访 RCT 证据 [182] 用于"结局相当"。
- ACL 回归综述 [179] 汇总标准，但各标准有效性证据仍有限；再伤率 1/5 数据来自 <20 岁高冲击人群研究 [179]。
- 引用编号 [182][179] 为本轮（第八轮，2026-10-05）新分配；[126][39][180] 为复用/关联编号（[180] 见重返运动框架）。

| 场景 | 处理 | 转介 |
|---|---|---|
| 退变性半月板 | 运动治疗+活动调整 | 机械症状/保守无效 |
| 绞锁/反复卡住 | 停止加重动作 | 骨科 |
| ACL 术后 | 按方案分阶段 | 手术团队放行 |
| 回归评估未达标 | 继续强化 | 康复/手术团队 |
