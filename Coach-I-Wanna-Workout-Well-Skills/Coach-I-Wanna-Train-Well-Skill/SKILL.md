# Train Well

把训练目标转成符合时间、器械、能力和恢复条件的计划。优先给用户能持续完成的起点，再根据记录调整。

## 接待与适用条件

单独调用时先按 [版本检查与地区来源](../references/version-updates.md) 检查更新，工具位于 `../scripts/check_version.py`；总控本次已检查时不重复执行。危险信号优先处理，不等待检查。

单独调用时按 [接待与反馈](../references/intake-and-feedback.md) 收集必要条件；总控已经收集的信息直接沿用。开完整计划前至少明确目标、年龄段与安全状况、经验、每周时间和器械。用户只问动作替换时，核对原动作目的、可用器械和不适情况即可。

有疼痛或训练中不适时先读 [Recover Well](../Coach-I-Wanna-Recover-Well-Skill/SKILL.md) 与相关主题；先处理危险信号，不直接开默认健康成人计划。不将“未提到疾病”当成“已确认无疾病”。

## 制定计划

1. **排期**：先落实每周能完成的天数与单次时长，再选择全身或分化。健康新手可从每周 2–3 天全身开始；不默认采用高频分化。
2. **选择动作**：覆盖与目标相关的蹲、髋主导、推、拉和躯干训练，兼顾已有运动负荷。优先安排当前目标最重要、技术要求较高的动作。器械与自由重量按能力和偏好选择。
3. **给起始剂量**：健康新手可参考每动作 1–3 个工作组、8–12 次、保留 2–3 次余力；先适应，再向适合个人的周容量调整。“每肌群约 10 组”是优化参考，不是第一周强制门槛。热身组不计工作组。
4. **确定重量**：未知训练重量时，用轻负荷试做，找到达到目标次数且仍有规定余力、技术稳定的重量。不虚构公斤数，不要求新手先测试最大重量。百分比与次数换算只是近似。
5. **核算可执行性**：考虑热身、完成各组、组间休息、换器械和场馆等候。多关节通常休息 2–3 分钟，辅助动作约 60–90 秒，按表现调整；时间不足先删低优先级动作或组数，不压缩必要休息硬塞计划。
6. **安排进阶**：写出加次数、加重量的实际触发条件，以及恢复不足时的退阶。不要按日历自动加重、加组或练到力竭。

力量目标不能让新手直接跳到最大重量或力竭测试；先建立技术和耐受，再在知识库支持的负荷区间内调整。有经验者参考当前实际容量与表现，不把更接近力竭当成所有人的必需条件。

动作替代按目标肌群、运动模式、技术要求、活动范围和设备选择，不机械地把相同组次与公斤数搬过去。说明如何重新找起始负荷；疼痛替代先筛查，不承诺换一个动作就安全。

## 计划成品

完整计划给出以下信息；局部请求只输出相关部分：

- 目标、适用条件、已知限制与待确认假设。
- 每周排期、训练日之间的恢复安排，以及单次预计时长。
- 按训练日列动作表：`动作 | 工作组 × 次数 | 起始负荷选择 / RIR | 休息 | 替代动作`。
- 简短热身与必要技术提示，区别热身组和工作组。
- 周容量核对：主要肌群的直接工作组与复合动作的间接参与分开说明，不把一组对所有参与肌群都计为一个完整直接组；自重与单侧动作说明计数口径。
- 明确进阶、漏练、疲劳和疼痛的处理条件。
- 今天的首个动作、需要记录的指标和首次反馈时间。

检查组数、排期与时长相互一致。用 [三天增肌案例](../references/train-worked-example.md) 对照完整交付方式；其中的动作与重量规则是示例，不替代用户条件。

## 根据反馈调整

按 [接待与反馈](../references/intake-and-feedback.md) 获取实际组次、重量、余力、疼痛及恢复信息，再选择分支：

| 观察 | 下一步 |
| --- | --- |
| 同一动作连续两次训练所有工作组达到次数上限，技术稳定、达到目标余力且恢复正常 | 增加器械允许的最小合理负荷，参考主题文件 2%–10% 区间；增加后回到次数区间较低端。最小档位太大时先维持或增加次数，不强行跳档 |
| 仍在次数区间内，有进步、恢复正常 | 保持组数与重量，先争取多一次规范重复，不同时提高所有变量 |
| 达不到下限、动作变形或余力明显不足 | 先核对休息与负荷，降低重量或采用更易掌握的动作；技术失稳时结束该组 |
| 连续数次表现下降且疲劳、睡眠或酸痛影响训练 | 核对生活负荷，减少工作组或负荷，必要时短期减量；持续或异常症状转 Recover Well，不诊断过度训练综合征 |
| 一次漏练或可用时间减少 | 从下一可用日继续原顺序，必要时缩减当周安排；不把两次容量集中补到一天 |
| 连续数周无进步 | 先检查完成率、记录一致性、休息、饮食与恢复；这些足够且仍停滞时，再小幅改变一个训练变量并约定复查，不自动大幅加量 |
| 新疼痛、症状加重或危险信号 | 停止诱发动作并按 Recover Well 筛查；危险信号及时医疗处理，不等周复盘 |

输出调整后的具体安排与理由，明确下次检验哪个指标。训练后未酸痛不是加量依据；不承诺固定期限的围度或力量增长。

需要跨对话保存目标、训练计划或反馈时按 [本地长期档案](../references/long-term-memory.md) 检查状态和同意；仅在成功写入后说已保存，暂停或未同意时沿用当前对话。
