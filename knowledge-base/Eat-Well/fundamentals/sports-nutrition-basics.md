# Eat Well：运动营养基础（主题指南）
> [返回导读与主题索引](../../topic-index.md)
> 本文件为本主题的主要归属入口；交叉领域请按导读索引读取关联文件。

> 本文件回答健康会员的日常营养问题：吃多少能量？蛋白质怎么吃、吃多少？碳水该不该补？脂肪要不要怕？怎么喝水？补剂有没有用？增肌和减脂的饮食策略分别是什么。主要依据：ISSN 蛋白立场声明（2017）[13]、ISSN 膳食与体成分立场声明（2017）[14]、蛋白补充 meta 分析（2018）[15]、ACSM/ADA/DC 运动营养立场（2009）[16]。
> 疾病人群（糖尿病、高血压、高脂血症、高尿酸/痛风、慢肾、肥胖症）的饮食见 [Eat Well](../../Eat-Well/weight-management/fat-loss-and-special-populations.md)。
---
## 一、本主题回答哪些问题
1. 增肌一天要吃多少蛋白质？一次吃多少？什么时候吃？
2. 减脂怎么吃才能尽量保住肌肉？（热量缺口、蛋白量、减重速度）
3. 蛋白粉/补剂有没有必要？乳清、酪蛋白、大豆蛋白怎么选？
4. 运动前后碳水怎么吃？练后要不要猛补碳水？
5. 脂肪要吃多少？是不是越少越好？
6. 训练中/训练后怎么补水？
7. 生酮、低碳、间歇禁食能增肌减脂吗？
8. 素食者、女性、老年人训练者有什么特别注意？
---
## 二、核心结论（先给判断）
- **能量平衡决定体重方向**：减脂=持续热量赤字；增肌=适度热量盈余。膳食结构（低脂/低碳/生酮）在体成分结果上的差异总体很小，**依从性比模式更重要** [14]。
- **蛋白质是最重要的宏量营养素（对增肌减脂会员）**：
  - 断点模型估计约 **1.62 g/kg 体重/天**，95%CI **1.03–2.20**；分段模型相对线性模型比较 **p=0.079，未达统计显著**。约 1.6 是实践参考，不是个人最低门槛或已证明的硬平台 [15]；
  - ISSN 推荐运动者 **1.4–2.0 g/kg/天**，高压力期可达 2.0 g/kg [13]；
  - **较瘦、有抗阻训练经验、处于热量赤字的运动者**可参考 **2.3–3.1 g/kg 瘦体重（FFM）**；不外推给所有减脂会员 [14]。
- **单次蛋白摄入**：ISSN 一般建议约 **0.25 g/kg 体重，或 20–40 g** 高质量蛋白，按年龄、训练调整；理想间隔约 3–4 小时 [13]。本轮未核实“所有年轻人每餐 0.4 g/kg”和“所有老年人每餐至少 0.4 g/kg”为这两篇文献的统一推荐，不能把急性 MPS 最优剂量等同长期增肌保证。
- **蛋白时机不是关键**：只要总蛋白充足，练后"黄金窗口"（1 小时 vs 数小时）没有决定性差异 [13,15]；练后 0–2 小时吃 20–40 g 蛋白仍是稳妥做法。
- **碳水**：运动者每日 **6–10 g/kg**（耐力项目）[16]；一般力量训练者按活动量 3–6 g/kg 即可（本批文献未给力量人群精确值，此为应用建议，见证据限制）。运动中耐力场景 30–60 g/小时 [16]。
- **脂肪**：一般运动者占总能量 **20%–35%**；<20% 无额外好处 [16]。
- **补水**：脱水超体重 **2%–3%** 即损害表现 [16]；运动中补液量与出汗量匹配，运动后每减重 0.5 kg 补 **450–675 mL** 流质 [16]。
- **补剂**：以食物为基础的多样化饮食下，多数会员**不需要补剂**；蛋白粉只是方便的蛋白来源，不是必需品 [13,14,16]。

## 三、适用人群与条件
- 健康、参加力量/耐力训练的成年人。
- 数据基础：Morton meta [15] 纳入健康成人（多为年轻男性）；ISSN 立场面向运动人群 [13,14]；ACSM 立场面向运动员 [16]。
- 老年训练者：蛋白需要更高（合成抵抗）；ACSM 立场提示蛋白 1.2–1.7 g/kg 区间用于耐力/力量人群 [16]，老年上限更推荐 [13]。
- 女性：蛋白与能量原则相同；注意铁/钙摄入与经期铁损失 [16]。
- 素食/纯素：蛋白质可从大豆、豆制品、谷物组合获取；总量原则同样适用 [13,16]。
- 减脂会员、体重管理/慢病人群：见 [Eat Well](../../Eat-Well/weight-management/fat-loss-and-special-populations.md)。

## 四、决策规则（如果……则……）
### 蛋白质
- 如果会员是健康成人增肌中的力量训练者 → 每天 **1.6–2.2 g/kg**可作整合后的应用参考，约 1.6 g/kg 不是硬性底线；ISSN 一般范围是 1.4–2.0。**2.3–3.1 g/kg FFM**只针对较瘦、有抗阻经验且热量赤字的运动者，不能换成实际体重口径 [13,14,15]。
- 如果会员是新手增肌 → 1.6 g/kg 足够获得大部分收益，不必盲目堆高 [15]。
- 如果会员减脂 → 按体脂、训练经验、赤字和健康状况调整，不要求所有人取 2.3–3.1 g/kg FFM 上沿 [14]。
- 如果会员年龄较大 → 单次需要可能更高，应结合健康状况和全天需求；本轮不把固定年龄门槛、每餐 0.4 g/kg 和每日 1.2–1.5 g/kg 合写成 [13,15] 的统一处方。
- 如果会员问“一次吃多少” → 参考 0.25 g/kg 或 20–40 g，按全天需求分配；不强制额外增加一餐或固定餐数 [13]。
- 如果会员肾功能正常 → 高蛋白（2 g/kg 以上）在证据范围内安全；**已有肾脏病者先咨询医生（见 [Eat Well](../../Eat-Well/weight-management/fat-loss-and-special-populations.md) CKD 章节）** [13]。
- 如果会员问"要不要蛋白粉" → 先算食物摄入；吃不够再用补剂补差量，乳清/酪蛋白/大豆蛋白在增肌效果上差异很小 [13]。
### 碳水与能量
- 如果会员做高强度/长时间训练（耐力）→ 碳水 6–10 g/kg/天 [16]。
- 如果会员做力量训练、中等活动量 → 3–6 g/kg/天（应用建议，来源见证据限制）[16 延伸]。
- 如果是长时间、持续高能量需求的耐力运动等适用场景 → 可参考运动中补碳水 30–60 g/小时 [16]；普通力量训练超过 60 分钟不自动需要这个剂量，先看实际强度、持续运动时间、餐前摄入和恢复需求。
- 如果连续两天比赛/重训 → 练后即刻（30 分钟内）补 1.0–1.5 g/kg 碳水，之后每 2 小时补充以快速恢复糖原 [16]。
- 如果会员减脂 → 优先减脂肪/精制糖的能量，保留蛋白与碳水供能训练；不采用极低碳水与力量训练并存除非专业监督 [14]。
### 减脂速度与保肌
- [14] 的每周 0.5%–1.0% 来自健美备赛建议，不是按体脂高低划分所有成人的统一标准；较瘦者宜更慢，但 ≤0.5% 也不是统一保证。超重／肥胖的临床目标参见 [Eat Well](../../Eat-Well/weight-management/fat-loss-and-special-populations.md) [17]。
- 减脂期 LBM 流失 → 蛋白补足 + 抗阻训练保留肌肉 [14,15]。
- 如果减重平台 >4 周 → 重新核算摄入（减少 200–300 kcal 或增加活动），而非盲目砍碳水 [14]。
### 补水
- 训练前 → 训练开始前约 2 小时喝 500 mL 左右（应用建议）[16]。
- 训练中 → 每 15–20 分钟小口补水（与出汗量匹配；长时训练补钠，运动饮料电解质适用场景为 >60 分钟或大量出汗）[16]。
- 训练后 → 每减重 0.5 kg 补 450–675 mL [16]。
- 如果会员问"喝水会稀释电解质吗" → 大量白水+大量出汗时需要同时补钠；普通训练量不必担心 [16]。

## 五、可执行建议（计算与模板）
### 每日蛋白计算示例（70 kg 增肌者）
- 目标 1.6 g/kg → 112 g/天
- 分配：早餐 28 g + 午餐 32 g + 练后 20 g + 晚餐 32 g = 112 g（餐次分配为操作示例，具体食物需核对）
- 食物换算：100 g 鸡胸 ≈ 24 g 蛋白（来源：[Eat Well](../../Eat-Well/weight-management/fat-loss-and-special-populations.md) 慢肾章节的食物表数据，作为常见值参考）[24]
### 减脂起步模板（70 kg、每周 3 次力量训练者）
- 蛋白：1.6–2.0 g/kg（112–140 g）
- 碳水：3–4 g/kg（210–280 g）
- 脂肪：0.8–1.0 g/kg（约 25% 能量）
- 称重与趋势复查为应用安排，按个体调整；“连降 3 周后维持 1 周”未核实为 [14] 的固定要求。
### 训练日碳水时机模板（非耐力）
- 训练前 1–2 小时：小份主食（约 0.5–1 g/kg）
- 训练中：普通力量训练不因总时长超过 60 分钟就自动补糖；长时持续高需求运动才按适用条件参考 30–60 g/小时 [16]
- 练后：蛋白 20–40 g + 适量碳水（如恢复需求紧迫，按 1.0–1.5 g/kg 碳水补充）[13,16]

## 六、例外、禁忌、停止条件和需要专业评估的情况
- **肾脏病（CKD）、肝功能不全**：高蛋白饮食需在医生/营养师指导下调整（见 [Eat Well](../../Eat-Well/weight-management/fat-loss-and-special-populations.md)）[13,24]。
- **糖尿病患者**：运动+碳水策略需配合血糖监测与药物，防低血糖（[Eat Well](../../Eat-Well/weight-management/fat-loss-and-special-populations.md)）[20]。
- **进食障碍倾向**（节食失控、暴食-清除、体重恐惧）：教练不继续给热量处方，转介心理/营养专业（[Eat Well](../../Eat-Well/weight-management/fat-loss-and-special-populations.md) 亦提及转诊精神科）[17,25]。
- **痛风/高尿酸**：高蛋白（尤其动物内脏、海鲜）需按嘌呤限制执行（[Eat Well](../../Eat-Well/weight-management/fat-loss-and-special-populations.md)）[23]。
- 孕妇/哺乳期：热量需求增加（中晚孕期 +300/+450 kcal，哺乳 +400 kcal），不适用减脂目标 [17]。
- 出现不明原因体重骤降、持续乏力、月经紊乱（女性运动员三联征风险）→ 转介评估 [16]。

## 七、常见误区与证据限制
- **误区："练后 1 小时内不喝蛋白粉就白练"** → 总蛋白量与规律摄入比时机重要 [13,15]。
- **误区："蛋白质伤肾"** → 健康成人高蛋白（至 2 g/kg 水平）未显示肾损害；CKD 患者除外 [13]。
- **误区："吃蛋白质就会长肌肉"** → 蛋白只是原料，需要抗阻刺激与能量盈余配合 [13,15]。
- **误区："减脂必须低碳/生酮"** → 等热量等蛋白下各模式效果相近，选能坚持的 [14]。
- **误区："运动饮料每练必喝"** → 普通训练可按需喝水；长时高需求运动或大量出汗时分别评估碳水和电解质需求，时长不是唯一依据 [16]。
- **证据限制**：
  1. 1.6 g/kg 断点来自蛋白补充剂研究（受试者多为年轻男性、以食物+补充形式）[15]；对女性、老年人、纯素食者的精确剂量证据较少。
  2. 蛋白时机结论主要来自急性 MPS 研究，长期增肌差异小 [13,15]。
  3. 碳水 6–10 g/kg [16] 面向耐力运动员；力量训练者精确碳水需要量本批文献未直接给出，3–6 g/kg 为应用建议（非研究结论）。
  4. ISSN 立场声明 [13,14] 含作者利益冲突（部分受补剂行业资助），引用其结论时保留批判性。
  5. 中国居民膳食指南 [26] 已核对并补充（见文末"附"节）；注意：源 PDF 文件名标注"2026"，经版权页核对实际内容为《中国居民膳食指南（2022）》（人民卫生出版社 2022.4），引用一律按 2022 版处理。

## 附：中国居民膳食指南（2022）核心推荐量（供一般健康会员对照）
> 来源 [26]《中国居民膳食指南（2022）》（中国营养学会）。适用 2 岁以上一般健康人群；面向运动员的专项推荐见上文 [13]–[16]。本表解决会员常问的"普通人到底该吃多少"。
| 项目 | 推荐量（2022 版） |
|---|--- |
| 食物多样 | 每天 ≥12 种食物，每周 ≥25 种 |
| 谷类 | 200–300 g/天（其中全谷物和杂豆 50–150 g，薯类 50–100 g） |
| 蔬菜 | 每天 ≥300 g，深色蔬菜占 1/2 |
| 水果 | 200–350 g/天（果汁不能代替鲜果） |
| 奶及奶制品 | ≥300 ml/天液态奶当量 |
| 动物性食物 | 120–200 g/天（鱼每周 2 次或 300–500 g；畜禽肉 300–500 g/周；蛋类 300–350 g/周） |
| 盐 | <5 g/天 |
| 烹调油 | 25–30 g/天 |
| 添加糖 | <50 g/天，最好 <25 g |
| 饮酒 | 成年人如饮酒，酒精量 ≤15 g/天；儿童青少年、孕妇、乳母不应饮酒 |
| 饮水 | 低活动水平成人：男性 1700 ml/天、女性 1500 ml/天 |
| 三餐能量分配 | 早餐 25%–30%、午餐 30%–40%、晚餐 30%–35% |
| 宏量营养素供能比 | 碳水 50%–65%、蛋白质 10%–15%、脂肪 20%–30% |
**与运动会员相关的应用提示（应用建议，非指南原文）**：
- 指南宏量营养素比例面向一般人群；力量训练会员的蛋白需要通常高于 10%–15%（按绝对量 1.6 g/kg 见上文 [15]），两者不冲突——指南给出供能比框架，运动文献给出绝对量。
- 指南运动推荐：每周 ≥5 天中等强度身体活动、累计 ≥150 分钟；主动身体活动每天最好 6000 步；减少久坐、每小时起来动一动 [26 准则二]。
